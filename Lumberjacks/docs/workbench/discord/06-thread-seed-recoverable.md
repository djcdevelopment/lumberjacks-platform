**Both pieces from this thread now run — here is where they went**

This thread was opened for two things that had been pruned out of the repo: a camera flythrough
that never had a flight mod, and a quest submission bridge that was never wired to anything.
Neither is recoverable any more. Both got built, and each has its own thread in this forum now.

**World photography → gallery** — the flythrough plan was replaced rather than revived. It shoots
stills instead of video: it reads a world save, finds every structure people built, works out where
a camera should stand for each one, and photographs them unattended. Last run was 1,411 photographs
across 161 structures, none of them framed by a human. See the **"World photography → gallery"**
thread.

**Quest submission → review bridge** — turned out never to be a port. The live mod does not produce
the screenshot-and-trace evidence envelope the old consumer expected; its proof is the durable
EventLog row. That design call is decided in ADR 0018, the bridge is ported to it, and what remains
is one live in-game run. See the **"Quest submission → review bridge"** thread.

Both still have real work open, and both claiming tasks are live in their own threads — CG-1 for
the camera plugin, QB-1 for the bridge's live proof. Nothing here is closed, it is just no longer
*recoverable*, which is a different word.
