# Security Policy

`lumberjacks-platform` is pre-alpha software maintained by one operator. Only
the latest `main` revision is supported; there are no maintained release
branches yet.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security** tab and **Report a vulnerability**. If private
vulnerability reporting is unavailable, email `licensing@djcdevelopment.com`
with a subject beginning `[SECURITY]`.

We aim to acknowledge reports within seven days and, within 90 days, provide a
fix, mitigation, or accepted-risk disposition. Please hold public disclosure
for 90 days or until a fix ships, whichever comes first. There is no bounty
program.

## Scope

This repository and its operated Gateway, Companion, Workbench, P7, and live
FieldLab surfaces are in scope. The `networksense`, `comfy-quest`, `isolate`,
and `baseline` repositories have separate ownership and disclosure scopes.
